## FileBox をダウンロード

### [⬇ FileBox-Setup.exe をダウンロード](https://github.com/miki-826/FileBox/releases/download/preview/FileBox-Setup.exe)

1. **FileBox-Setup.exe** を実行すると、最新版のダウンロードが始まります。
2. 取得と展開が終わるまで待ちます。進捗を画面で確認できます。
3. **「FileBox を起動」**を押して使い始めてください。

Windows 10 1809 以降 / Windows 11 の x64 用です。必要な .NET 8 と Windows App SDK は本体に同梱しています。

保存先は `%LOCALAPPDATA%\Programs\FileBox\preview-…\app` です。「保存先を開く」から確認できます。更新時も既存の本体やユーザー設定を上書きしません。

### ZIP で取得する場合

[本体 ZIP を直接ダウンロード](https://github.com/miki-826/FileBox/releases/download/preview/FileBox-preview-win-x64.zip) → すべて展開し、`FileBox.exe` を起動してください。`indexer` フォルダも必要です。

[EXE の SHA-256](https://github.com/miki-826/FileBox/releases/download/preview/FileBox-Setup.exe.sha256) ／ [ZIP の SHA-256](https://github.com/miki-826/FileBox/releases/download/preview/FileBox-preview-win-x64.zip.sha256)

これは**開発プレビュー**です。製品版ではありません。署名していないため、Windows が発行元を確認できない旨を表示する場合があります。EXE の取得と初回の準備にはインターネット接続が必要です。ダウンロード中の通信エラーは「再試行」でやり直せます。
