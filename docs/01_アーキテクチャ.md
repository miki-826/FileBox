# 01. アーキテクチャ

## 1. 全体構成
```
┌──────────────────────────── ユーザーセッション（通常権限） ────────────────────────────┐
│                                                                                        │
│  ┌──────────────── FileBox.App (WinUI 3) ────────────────┐   ┌── FileBox.Shell ──────┐ │
│  │ Views (XAML)  ←→  ViewModels (CommunityToolkit.Mvvm)  │   │ ・URIハンドラ           │ │
│  │        │                                              │   │   filebox://           │ │
│  │        ▼                                              │   │ ・保存ダイアログ監視    │ │
│  │  FileBox.Core（提案/検索クエリ/クォータ/権限/監査）    │◀─▶│   (UI Automation)      │ │
│  │        │                       │                      │   │ ・トースト通知          │ │
│  │        ▼                       ▼                      │   └───────────────────────┘ │
│  │  FileBox.Data (SQLite)   IndexClient (Named Pipe)     │                             │
│  └────────────────────────────────┬──────────────────────┘                             │
└───────────────────────────────────┼────────────────────────────────────────────────────┘
                                    │  \\.\pipe\FileBox.Index（ユーザーSIDでACL制限）
┌───────────────────────────────────┼──────── Windows サービス（LocalSystem） ─────────────┐
│  FileBox.Indexer                  ▼                                                     │
│   ├ VolumeScanner   : MFT列挙 (FSCTL_ENUM_USN_DATA)                                     │
│   ├ UsnWatcher      : USNジャーナル追従 (FSCTL_READ_USN_JOURNAL)                         │
│   ├ FallbackWatcher : FileSystemWatcher + 再帰走査（FAT/exFAT/ネットワーク）             │
│   ├ NameIndex       : メモリ常駐の名前索引（検索本体）                                   │
│   ├ SizeAggregator  : フォルダ容量集計（クォータ用）                                     │
│   └ Snapshot        : インデックスの定期永続化（起動高速化）                             │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```

## 2. ソリューション構成
| プロジェクト | 種別 | 責務 |
|---|---|---|
| `FileBox.App` | WinUI 3 アプリ (MSIX) | 画面、タブ/ペイン、プレビュー、ViewModel |
| `FileBox.Core` | クラスライブラリ | 保存先提案エンジン、検索クエリパーサ、クォータ判定、権限判定、ファイル操作サービス、監査 |
| `FileBox.Data` | クラスライブラリ | SQLite アクセス (Microsoft.Data.Sqlite + Dapper)、マイグレーション |
| `FileBox.Indexer` | Worker Service (Windows サービス) | インデックス構築・変更追従・検索実行・容量集計 |
| `FileBox.Contracts` | クラスライブラリ | App⇔Indexer 間の IPC メッセージ定義（MessagePack） |
| `FileBox.Shell` | クラスライブラリ＋常駐トレイプロセス | URI起動処理、保存ダイアログ連携、受け取りボックス監視、通知 |
| `FileBox.Tests` | xUnit | 単体テスト（提案エンジン・クエリパーサ・クォータ・権限） |

## 3. 主要コンポーネントの責務
### 3.1 ファイル操作サービス (`Core.FileOperationService`)
FileBox 内のすべての保存・コピー・移動・削除・リネームは必ずここを通す。処理パイプライン:
```
要求 → 権限チェック(PermissionService) → 容量チェック(QuotaService)
     → 実行(IFileOperation COM: Undo・ごみ箱対応) → 監査ログ → 学習(SaveHistory) → 通知
```

### 3.2 インデックス (`Indexer`)
- 検索はサービス側のメモリ索引で実行し、結果だけを App に返す（App のメモリを圧迫しない）
- 管理者権限が必要な MFT/USN アクセスをサービスに隔離し、UI は通常権限で動作
- 検索結果は返却前に「要求ユーザーが閲覧権限を持つか」でフィルタ（FileBox 権限 + NTFS ACL）

### 3.3 IPC
- Named Pipe + MessagePack、要求/応答とストリーミング（検索結果のチャンク送信）に対応
- 各要求に `CancellationId` を持たせ、入力のたびに前回検索をキャンセル

## 4. 技術選定
| 領域 | 採用 | 理由 |
|---|---|---|
| UI | WinUI 3 | Fluent デザイン、Windows 11 との一体感、タブ (TabView) 標準 |
| MVVM | CommunityToolkit.Mvvm | ソースジェネレータで記述量削減 |
| DB | SQLite (WAL) | 単一ファイル・サーバ不要・FTS5 |
| ファイル操作 | Shell `IFileOperation` | エクスプローラーと同じ進捗・競合ダイアログ・Undo・ごみ箱 |
| プレビュー | WebView2 / `IPreviewHandler` | PDF・Office 等を既存プレビューハンドラで表示 |
| 保存ダイアログ連携 | UI Automation (`System.Windows.Automation` / UIA3) | 他アプリのコモンダイアログを非侵襲に検知・操作 |
| 通知 | Windows App SDK AppNotification | トーストからの操作（「ここへ移動」ボタン） |
| 認証 | Windows サインイン（トークン SID）＋ Windows Hello / CredUI | 独自ログイン不要でエクスプローラーと同じ使い勝手、パスワードを保持しない |
| シェル統合 | `IShellFolder` / `IContextMenu` / `IShellItemImageFactory` | 特殊フォルダ・他アプリの右クリック項目・サムネイルをエクスプローラー同等に |
| 配布 | MSIX + サービスインストーラ | URIスキーム・サービス登録を一括 |

## 5. プロセスと起動
1. OS起動時: `FileBox.Indexer` サービス開始 → スナップショット読込 → USN 差分適用
2. ログオン時: `FileBox.Shell` トレイ常駐（受け取りボックス監視、保存ダイアログ監視、URI受付）
3. ユーザー操作時: `FileBox.App` 起動（単一インスタンス。2回目以降の起動・URI起動・Win+E・フォルダを開く操作は既存ウィンドウへリダイレクト: `AppInstance.FindOrRegisterForKey`）
   - **ログイン画面なし**。利用者はプロセスのトークン（Windows サインイン中のユーザー SID）で自動的に識別する
   - Indexer 側は Named Pipe の接続元を `GetNamedPipeClientProcessId` + `ImpersonateNamedPipeClient` で確認し、App の自己申告ではなく OS が保証する SID で権限判定する

## 6. ディレクトリ配置
| 用途 | パス |
|---|---|
| ユーザー設定・DB | `%LOCALAPPDATA%\FileBox\filebox.db` |
| 共通DB（アカウント・クォータ・権限） | `%PROGRAMDATA%\FileBox\system.db`（管理者のみ書込可） |
| インデックススナップショット | `%PROGRAMDATA%\FileBox\index\<VolumeSerial>.snap` |
| ログ | `%LOCALAPPDATA%\FileBox\logs\` |
