# 00. 概要 — ファイルボックス (FileBox)

## 1. 目的
Windows エクスプローラーの代わりとなるファイル管理アプリ。次の不満を解消する。

- 保存のたびに保存先フォルダを手で探して指定する手間
- 細かい手作業によるフォルダ整理
- ファイル数が多いフォルダでの検索の遅さ

## 2. 想定ユーザー
| ペルソナ | 特徴 | 主な利用シーン |
|---|---|---|
| 個人ユーザー | 書類・写真・課題などをPCに大量保存 | 保存先の自動提案、高速検索 |
| 家族で共有するPCの管理者 | 1台のPCを複数人で使う | アカウントごとの容量制限・権限 |
| 予定管理を重視する人 | カレンダーで作業を管理 | 予定からリンクで資料フォルダを開く |

## 3. 前提・決定事項
| 項目 | 決定 |
|---|---|
| プラットフォーム | Windows 10 (1809+) / 11 |
| 技術 | C# / .NET 8 / WinUI 3 (Windows App SDK) |
| 管理対象 | PC全体（既存フォルダ構造をそのまま扱う） |
| 容量制限・権限の強制範囲 | FileBox 経由の操作（オプションで NTFS クォータ/ACL と連動） |
| 認証・ログイン | **アプリ独自のログイン画面は設けない**。Windows のサインインをそのまま利用（エクスプローラーと同じく、起動したら即使える） |
| 位置付け | エクスプローラーの代替として日常的に使えるレベル（Win+E・フォルダを開く操作の置き換えに対応） |
| 保存先の提案 | ローカル推定のみ（外部APIは使わない・オフライン動作） |

## 5. 用語集
| 用語 | 意味 |
|---|---|
| インデックス | PC内の全ファイル/フォルダ名とメタ情報を保持する FileBox 独自の検索用データ |
| フォルダプロファイル | フォルダ内のファイル名から抽出した「特徴語」とその重み。保存先提案に使う |
| 受け取りボックス (Inbox) | ダウンロード・デスクトップ等の監視対象。新着ファイルの振り分け待ち一覧 |
| ペイン | メイン画面を分割した1区画。フォルダビューまたはプレビューを表示 |
| ワークスペース | タブとペインの配置をまとめて保存したもの |
| クォータゾーン | 容量上限を設定したフォルダ（とその配下） |
| ブックマーク | ファイルIDで追跡される、移動しても切れないリンク対象 |
| ロール | 権限と容量上限のテンプレート（管理者/一般/ゲスト等） |

## 6. スコープ外（初期版）
- クラウドストレージ（OneDrive/Google Drive）の API 直接連携（同期フォルダとしてはローカル扱いで対応）
- ネットワーク越しの複数PC間アカウント共有
- ファイル内容の全文検索（将来拡張: Windows Search / IFilter 連携を検討）
- macOS / Linux 対応
