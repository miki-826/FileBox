- 右上の 👤 は Windows のサインインユーザーを表示するだけ（ログアウト・切替ボタンは置かない。切替は Windows のユーザー切替で行う）
- 検索バーは常に表示。入力すると現在タブに「検索結果ペイン」を追加（Enter で新タブ）
- チップとクエリ文字列は双方向同期
- ファイル右クリック: 開く / プレビューで開く / 隣のペインで開く / 移動（提案付き）/ リンクをコピー / ブックマーク / プロパティ
- ショートカット: `Ctrl+T` 新タブ, `Ctrl+\` 分割, `Ctrl+F` 検索, `Ctrl+Shift+L` リンクコピー, `Space` プレビュー

## 9. デザイン方針
- WinUI 3 の Fluent（Mica 背景）、ライト/ダーク追従
- 主要操作はすべてキーボードで可能、ナレーター対応（AutomationProperties 設定）
- 提案には必ず「理由」を表示し、ユーザーが納得して選べるようにする

### 開発プレビューの表示調整（2026-10-18）
- 機能・検索条件・ショートカットは維持し、検索領域、サイドバー、タブ内の区画、ステータスの境界と余白を整理。
- 検索欄は短い入力例とし、検索チップは幅が足りないとき横スクロールできる。設定・管理はサイドバー下部に固定する。
- フォルダ一覧は最小行高36、検索結果は54。ファイル名・場所のツールチップとアイコンボタンの読み上げ名を付ける。
- 受け取りボックスはファイル情報・推奨先・提案理由を別の行に配置し、理由は折り返す。一括振り分けをアクセント色で示す。
- 色は WinUI のテーマリソースを使い、ライト／ダークとシステムのアクセント色に追従する。


### 機能配置とアイコンの整理（2026-10-19）
- 上部は「移動 → 場所 → 検索 → 検索条件」の1行。検索条件はボタンから開くパネルに集約し、対象・一致方法・種類と更新日・範囲の見出しで区別する。条件数をボタンに表示し、検索語を残して条件をリセットできる。
- フォルダ一覧の直上には名前付きの操作バーを置く（新規フォルダ、切り取り、コピー、貼り付け、名前の変更、削除、日付でまとめる、プレビュー）。選択内容に応じて有効化し、幅が足りない操作はメニューへ収める。移動用のアドレス欄は分割時だけ区画内にも表示する。
- サイドバー上部に PC の入口を固定し、クイックアクセス → お気に入り → 最近使ったフォルダ → ドライブと場所の順に並べる。ネットワークとごみ箱は「ドライブと場所」内。表示中の場所を強調し、ドライブ詳細はツールチップと PC の一覧で確認する。
- ワークスペース・保存した検索は「保存した作業」の開閉領域へまとめる。区画の分割は名前付きメニューから左右／上下を選択する。タブのアイコンは機能に合わせる。
- 一覧・検索・受け取りで共通のベクターアイコンを使用。フォルダは塗りのあるタブ付きフォルダ、ドライブはディスク、ファイルは紙型と種類の印（PDF・W・X・P・ZIP、画像・動画・音楽など）で区別する。既存のフォルダ色も反映する。
- ウィンドウ幅1150未満ではブランド表示を省き、サイドバーを212pxにしてアドレスと検索欄の幅を確保する。


### フォルダ容量とダウンロードの整理（2026-10-19）
- フォルダ一覧のサイズ列に、配下のファイルの合計容量を表示する。先に一覧を表示し、容量は非同期で反映する。サイズ順の並べ替えにもフォルダ容量を使う。
- 索引を優先し、索引対象外の場所は読み取り専用の走査で集計する。再解析ポイントは辿らない。集計中・約（集計途中または一部取得不可）・未集計・取得不可を区別し、未取得を0と表示しない。移動・更新時は古い集計をキャンセルする。
- サイドバーの独立した「受け取りボックス」を廃止し、「ダウンロード」内の操作「整理の提案」から「ダウンロードの整理」を開く。新規利用時の監視先はダウンロード。既存の監視先・ルールは保ち、整理画面に対象の場所を表示する。以前の `--inbox` や保存済み区画もその画面へ開く。
- 容量画面はドライブの使用中／空き／全体と、選択した場所のファイル合計・件数・フォルダ別内訳を表示。棒と割合は選択した場所の合計を100%とする。フォルダ名でさらに内側へ進める。
- 大きいファイル一覧と容量上限設定は開閉領域にまとめる。大きいファイルは内訳に含まれる項目で、合計に重複加算しない。ドライブの使用量とファイルの論理サイズの差も画面で説明する。
