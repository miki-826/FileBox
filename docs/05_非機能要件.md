# 05. 非機能要件

## 1. 性能目標
| 項目 | 目標 | 条件 |
|---|---|---|
| 名前検索の応答（先頭100件） | < 100ms | 100万エントリ、部分一致 |
| フォルダ名のみ検索 | < 30ms | 同上 |
| 前方一致検索 | < 10ms | 同上 |
| 初回インデックス構築 (MFT) | < 30秒 | NTFS SSD、100万エントリ |
| 再起動後に検索可能になるまで | < 5秒 | スナップショット＋USN差分 |
| 変更の反映遅延 | < 1秒 (NTFS) / < 5秒 (その他) | |
| 保存先提案の算出 | < 150ms | 入力ごと |
| Indexer 常駐メモリ | < 300MB | 100万エントリ |
| App 起動〜操作可能 | < 1.5秒 | コールドスタート |
| フォルダを開く操作〜表示（常駐時） | < 300ms | エクスプローラー置き換え時の体感をエクスプローラー同等に |
| 1万件フォルダの一覧表示 | < 500ms | 仮想化リスト |

## 2. セキュリティ
| 脅威 | 対策 |
|---|---|
| 悪意ある `filebox://` リンク（パストラバーサル、実行誘導） | パスを `Path.GetFullPath` で正規化後に検証、デバイスパス (`\\?\`, `\\.\`) 拒否、UNC は許可リストのみ、実行可能ファイルは開かず選択表示のみ、権限チェック |
| ブックマークの総当たり | トークンは 128bit 乱数（Base62） |
| IPC のなりすまし | Named Pipe の ACL を対話ユーザー SID と SYSTEM に限定、要求元プロセスのセッションID・ユーザーを検証 |
| 権限昇格（サービスが LocalSystem） | サービスはファイル内容を読まず、メタ情報の返却とDB更新のみ。結果は要求ユーザーの NTFS ACL でフィルタ（`AccessCheck`） |
| なりすまし・パスワード漏えい | FileBox はパスワードを保持しない（Windows サインインに委譲）。識別は IPC 接続元の OS トークン SID で行い、App からのユーザー名申告は信用しない。管理操作のみ Windows Hello / 資格情報で再確認 |
| 席を離れた隙の管理操作 | 管理操作ごとに本人確認（5分間はキャッシュ）、Windows のロックに従う |
| system.db の改ざん | `%PROGRAMDATA%` に配置し管理者・SYSTEM のみ書込可 |
| 監査ログの改ざん | 一般ユーザーは参照不可、追記のみの API |

## 3. 信頼性
- ファイル操作は Shell `IFileOperation` を使用（ごみ箱・Undo・競合解決）
- 自動振り分けは必ず Undo 可能で、移動履歴を 30 日保持
- インデックス破損・USN ジャーナル消失時は自動再構築（その間は FileSystem 直接検索にフォールバック）
- Indexer 停止時、App はフォルダ閲覧のみ可能な縮退モードで動作

## 4. 互換性・制約
- Windows 10 1809 以降 / Windows 11、x64 と ARM64
- Windows Home でも全機能が動作すること（FSRM 等の Server 機能に依存しない）
- 長いパス（> 260 文字）対応（`\\?\` プレフィックスを内部で使用）
- OneDrive のオンライン専用ファイル（プレースホルダ）は開く・プレビュー時のみダウンロード、容量集計は「ローカル占有サイズ」と「論理サイズ」を区別

## 5. 運用・保守
- ログ: Serilog、ローリング 7 日、ログレベルは設定で変更
- クラッシュレポート: ローカル保存のみ（外部送信しない）
- 設定のエクスポート/インポート（JSON）
- 自動テスト: 提案エンジン・クエリパーサ・権限判定・クォータ判定は単体テストでカバレッジ 80% 以上

## 6. リスクと対策
| リスク | 影響 | 対策 |
|---|---|---|
| 他アプリの保存ダイアログを検知できない（独自UI・Electron 等） | 入口③が使えない | 受け取りボックスで事後振り分け。対応アプリ一覧を公開 |
| MFT 読み取りに管理者権限が必要 | インストール時の昇格 | サービスとしてインストール時に1回だけ昇格。非管理者環境では FileSystemWatcher 方式 |
| PC全体対象のため権限・容量はアプリ外操作で迂回可能 | 制限が形骸化 | 監視＋警告、OS強制モード（NTFS ACL・ディスククォータ）を提供し、仕様として明示 |
| 提案精度が低いと逆に手間 | 体験の悪化 | 理由表示・学習・確信度が低い時は自動移動しない |
| メモリ使用量（数百万ファイル環境） | 常駐負荷 | 除外フォルダ設定、名前ヒープの圧縮、Trigram のオンデマンド構築 |
| ウイルス対策ソフトによる UIA/USN の誤検知 | 動作阻害 | コード署名、Microsoft への申請 |
| エクスプローラー置き換え時に FileBox が落ちるとフォルダが開けない | 日常操作が止まる | 2秒応答なしで explorer.exe へ自動フォールバック、HKCU のみ変更・元の値を保存して完全復元 |
| `explorer.exe /select,` を直接呼ぶアプリは置き換え不可 | 一部導線でエクスプローラーが開く | 制約として明記。常駐プロセスが新規エクスプローラーウィンドウを検知し「FileBox で開き直す」通知を出すオプション |
