# FileBox ファイル変換の実装仕様

更新日: 2026-10-20。Windows 10 1809 以降／Windows 11 x64 の開発プレビューへ、ローカルでの変換・編集・整理を追加する。既存の C#／.NET 8／WinUI 3、権限確認、監査、プレビュー、インストーラーを使用する。

## 利用の流れ

一覧の「変換・整理」またはファイルの右クリックから開く。入力の追加・除外、PDF の順序、処理とオプション、出力先を確認して実行する。種類に対応しない入力はスキップし、成功・失敗・スキップ・キャンセルをファイルごとに表示する。完成した出力の場所を開ける。OCR・抽出テキストを画面で読み、コピーできる。画像の結果には処理前後を並べて表示する。

エクスプローラー連携は `HKCU\Software\Classes\*\shell\FileBox.Tools` と `Directory\shell\FileBox.Tools` に独自動詞を追加する。既定動詞を変えず、設定をオフにすると独自キーを削除する。インストーラーのアンインストールでも解除する。Windows 11 の従来メニューから開く。静的な Document 動詞のため一度の選択は15件まで。起動要求を800msまとめて単一の画面へ渡し、FileBox 内ではさらに追加できる。種類別の操作選択はアプリ側で行う。

| 場所 | 責務 |
|---|---|
| `FileBox.Core/Tools/ToolCatalog.cs` | 操作・形式・パラメーター・入力検証 |
| `FileBox.Core/Tools/DataConversion.cs` | 厳密な文字コード、CSV、JSON、INI、改行、PDFページ範囲 |
| `FileBox.Core/Tools/MediaCommands.cs` | コーデック対応表とシェルを使わないコマンド引数 |
| `FileBox.Core/Tools/SafeOutput.cs` | 一時領域、衝突回避、公開、作業領域の掃除 |
| `FileBox.Core/Tools/SafeArchives.cs` | ZIP/TAR、展開パス・リンク・容量の検査 |
| `FileBox.Core/Tools/ExternalProcess.cs` | 外部プロセス、出力制限、タイムアウト、プロセスツリーの中止 |
| `FileBox.Core/Tools/FolderInspection.cs` | 空フォルダ・深さ付きツリー |
| `FileBox.Tools/ToolEngine.cs` | PDFsharp による結合と外部エンジンの実行。一時領域だけへ出力 |
| `FileBox.App/Services/NativeConversion.cs` | Windows OCR、PDF ページの PNG/JPEG 化、既存 IFilter によるテキスト抽出 |
| `FileBox.App/Services/ConversionService.cs` | 一括処理、権限・実容量の確認、監査、最終保存 |
| `FileBox.App/Views/ConversionDialog.cs` | 入力順、設定、進捗、中止、結果、比較・テキスト表示 |
| `FileBox.App/Views/ConversionSettings.cs` | エンジン、メニュー表示、出力先、任意のシェル登録 |

Core は外部パッケージに依存しない。PDFsharp は独立した `FileBox.Tools` で参照する。アプリを Web サイトとして配信する構成ではなく、Vercel・クラウド API・アカウント・同期の追加はない。UI は既存の WinUI コントロールを使い、追加画像アセットは使用しない。

## 機能と対応形式

形式名はエンジンが実行できることを保証するものではない。実行時にライター／エンコーダーの有無と実行結果を確認し、対応しなければ理由と変更方法を表示する。

| 分類 | 実装した機能と指定できる内容 |
|---|---|
| 画像 | PNG/JPEG/WebP/HEIC/HEIF/ICO/GIF/SVG/BMP/TIFF の読み取り。PNG/JPEG/WebP/HEIC/ICO/GIF/BMP/TIFF への変換。SVG は内蔵 MSVG による読み取りのみ |
| 画像編集 | 幅・高さ、縦横比維持、1920/1280/800/512 のプリセット、画質、目標 MiB、任意角回転、元サイズへの切り抜き、透明な余白／背景色、メタデータ削除、指定色と許容差による背景透明化 |
| OCR | Windows に導入済みの言語から選択。結果を TXT へ保存し、表示・コピー。言語パック不足を通知 |
| 動画 | MP4/MKV/MOV/AVI/WebM/WMV/M4V/MPEG/MTS/M2TS 等から MP4/MKV/WebM/MOV へ。H.264/H.265/VP9/AV1、CPU/NVENC/QSV/AMF を対応表で選択 |
| 動画編集 | 開始・終了秒、精密な再エンコード／高速コピー、画質・目標容量、解像度・縦横比、90度単位の回転、GIF の幅・FPS、指定時刻の PNG/JPEG、音声抽出 |
| 音声 | MP3/WAV/AIF/AIFF/AAC/OGG/WMA/M4A/FLAC/Opus の相互変換。複数選択の個別結果 |
| PDF | 既存のプレビューを維持。指定順の結合、新規 PDF 保存、ページ範囲・36～600 DPI の PNG/JPEG、IFilter で取得できる本文の TXT 保存 |
| CSV | 区切り文字、入力文字コード、見出し行の指定。JSON/XML/HTML/Markdown への変換。引用符・引用符内改行を解釈し、列数不一致・見出しの空欄／重複は拒否 |
| JSON | 妥当性検証・整形、全階層のキーを序数順に整列、CSV/XML 化。配列順を維持。重複キーは拒否。CSV はオブジェクト配列が対象で、ネスト値は JSON 文字列として保持 |
| INI/CFG/CONF | `[section]` と `key=value` を JSON/XML 化。重複キー・構文違いは失敗。コメントは保持せず、値は文字列 |
| 文字コード・改行 | UTF-8／BOM付きUTF-8／UTF-16 LE・BE／Shift_JIS。変換不能文字や不正バイトは失敗。CRLF/LF/CR。原拡張子を維持した別名コピー |
| アーカイブ | ZIP/TAR/tar.gz を標準機能で作成・展開。7z の作成と7z/RAR等の展開は 7-Zip。新規フォルダへ展開し、リンク、パス、容量を検査 |
| 整理 | 既存の重複検出・容量分析・一括リネームを再利用。任意の深さのツリーを TXT 保存。空フォルダの再帰検出と選択削除 |
| JAR | Java/CFR でクラスからソース相当を別フォルダに保存。対象 JAR を実行しない。権利・ライセンス確認を毎回必須とする |

JSON/XML は `data` を根とし、オブジェクトを `property name="元のキー"`、配列を `item`、null を `null="true"` で表す。任意の JSON キーを XML 要素名へ無理に置き換えない。

## 原本保護と権限

- 元ファイルを上書きしない。出力名には `_converted` 等を付け、同名があれば `(2)` 以降を割り当てる。公開時の `File.Move(..., overwrite:false)` または `Directory.Move` でも再確認する。
- 出力先に `.FileBox-<乱数>` の作業ディレクトリを作り、完成・権限・実サイズを確認してから最終名に移す。失敗・中止時はこの作業領域だけを削除する。入力フォルダの中に作業領域がある場合、圧縮とツリーの入力から除外する。
- `Guard` で入力の Read と出力先の Create、結果の実サイズによるクォータを確認する。圧縮対象の配下も Read を確認する。権限・容量が不明な管理対象ゾーンには保存しない。監査には操作、パス、結果と一般的な失敗種別を記録する。
- 外部エンジンの標準エラーには内容が含まれる可能性があるため、詳細は結果画面だけで確認し、アプリログや監査詳細に転記しない。
- 1件の失敗で残りを止めない。PDF結合・アーカイブ作成は複数入力で1出力の処理とし、そのグループで同じ結果を表示する。中止済みの残り入力はキャンセルとして記録する。
- 出力先と出力に再解析ポイントを許可しない。外部コマンドは絶対パスの EXE と `ArgumentList` で起動し、シェルを介さない。FFmpeg はローカルの形式・プロトコルを許可リストに限定する。
- ImageMagick は入力・出力コーダーを明示し、ファイル拡張子と異なる形式への無言のフォールバックを防ぐ。外部 delegate/filter を禁止し、SVG の DTD・スクリプト・外部参照を拒否する。画像の実処理は作業領域への入力コピーで行う。
- 重複削除は整理する組と残す1件を選び、残すパス・削除パス・件数を確認する。実行前に読み取りロックと SHA-256 再比較を行い、既存のごみ箱・Undo・監査を利用する。
- 空フォルダの起点とリンクは削除対象にしない。選択パスと件数を確認し、`Directory.Delete(recursive:false)` のみを使う。中身が増えれば削除は失敗する。空フォルダの削除はごみ箱を使わず、元に戻せないことを明示する。

## 設定と依存関係

新しい DB マイグレーションは不要。既存 `settings` テーブルに保存する。

| キー | 内容 |
|---|---|
| `tools.engine.ffmpeg/magick/7z/java/cfr` | 利用者が選んだ実行ファイル／CFR JAR の絶対パス |
| `tools.output` | 既定の出力先。空なら入力の場所 |
| `tools.preset.<ToolKind>` | 前回実行した `ToolOptions` の JSON |
| `tools.hidden.<ToolKind>` | `1` なら処理選択のメニューで非表示 |
| `tools.contextMenu` | エクスプローラーへの任意登録。既定はオフ |

エンジンパスとシェル登録は設定の持ち運びから除外する。設定ファイルを取り込んで実行ファイル指定や OS 登録が変わることはない。外部エンジンは同梱・自動インストールせず、実行ファイルの更新・対応形式・ライセンスは利用者の導入環境に従う。

同梱する PDFsharp 6.2.4 と Microsoft の関連パッケージは `src/FileBox.Tools/FileBox.Tools.csproj` で固定する。暗号パッケージは推移参照の8.0.1を使わず、修正済み8.0.2を明示する。著作権・許諾表示は `THIRD-PARTY-NOTICES.txt` として本体と ZIP に同梱する。外部エンジンのソースやバイナリはこのリポジトリへ取り込まない。

## 制限と異常系

- テキスト入力は64 MiB、SVG は16 MiB。PDF画像は一辺16384px・1億画素まで。OCR は OS の最大寸法に縮小し、その旨を表示する。PDFテキストは3200万文字を上限とし、切り捨てた成功にはしない。
- アーカイブ展開は10万項目・20 GiBまで。絶対パス、`..`、ADS、Windowsの予約名、リンク・特殊エントリ・重複を拒否する。7-Zip は実行前の一覧と実行後のツリーも検査する。暗号化／破損等はエンジンの失敗として扱う。
- ツリーは深さ1～30、最大1万項目。再解析ポイントは辿らない。到達できなかった部分を記載する。
- アニメーション・複数ページ画像の編集は先頭フレームが対象。SVGへのベクター化はしない。HEIC書き出しは対応ビルドが必要。
- 画像・動画の容量は目標値。画像は画質を下げて再試行し、未達を通知する。動画は指定区間と音声のビットレートを考慮するが、最終サイズを保証しない。
- 高速トリミングはキーフレームの誤差を実行前に説明する。WebMはVP9/AV1、VP9はCPUを使用する。GPUはエンコーダーの存在と実行結果で判定し、ハードウェア／ドライバー等の理由は結果の詳細に表示する。
- IFilter のネイティブ呼び出し中など、OS API から制御が戻るまで中止が待機する場合がある。外部エンジンは子プロセスごと終了する。プロセス出力は128 Ki文字、7-Zip一覧は32 Mi文字に制限して読み捨てを続ける。
- 生成された Java コードは元ソースと同一とは限らない。全JDK／全クラス形式の復元を保証しない。

## 検証と配布

基本コマンドはリポジトリ直下で実行する。

```powershell
dotnet test FileBox.sln
dotnet build src/FileBox.App -c Release -p:Platform=x64 -r win-x64 -p:SelfContained=true
dotnet list src/FileBox.Tools/FileBox.Tools.csproj package --vulnerable --include-transitive
./scripts/Package-Preview.ps1 -SkipBuild
```

2026-10-20 の確認結果:

- 228件のテスト成功。変換の境界値、欠落を防ぐ構文検査、文字コード、原本保護、衝突、ZIP/TAR/tar.gz、日本語のファイル名、不正な展開パス、リンク・容量、プロセス中止、PDF順序、設定の持ち運びを含む。

- 7-Zip の実エンジンで7z作成・展開。Java 21 と CFR 0.152 で自作クラスのJARからJavaソースを取得。
