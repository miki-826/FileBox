## 実装時に設計から変えた点
- **保存先の重み**（02 §1.3）: 学習 0.40 / 名前 0.30 / フォルダ名 0.10 / 拡張子 0.10 / 最近度 0.10。当初案では繰り返し選んだ保存先が一般語だけ一致するフォルダに負けたため
- **フォルダプロファイル**（03 folder_profiles）: DB に持たず、提案のたびに候補フォルダの中身から作る
- **候補から外す場所**: システム・アプリ内部に加え、`.` で始まるフォルダ、開発用の生成物（bin/obj/node_modules、Unity の Library 配下など）、今ファイルがある場所の配下
- **保存ダイアログ連携**（02 §1.2）: UI Automation ではなく WinEvent フック＋ウィンドウメッセージで実装（標準ダイアログならこれで足り、軽い）。ファイル名欄は ID 1001 の Edit。`Ctrl+Shift+Space` での表示切替は未実装（パネルの × で閉じる）
- **ブックマーク**（03 bookmarks）: system.db ではなく利用者ごとの user.db に保存（リンクはそれを作った人の PC で使う想定）
- **容量の集計**（02 §5.1）: 常時の差分集計ではなく、要求時に索引から配下を合計し 5 秒キャッシュ（ゾーン数は少ないため十分速い）
- **エクスプローラー置き換え**（02 §7.1）: 対象を実在のフォルダ（Directory）とドライブ（Drive）に限定。ごみ箱・コントロールパネルなどの仮想フォルダ（Folder）は奪わない（開けない場所で Windows 側の操作を壊さないため）
- **system.db の保護**: 管理者（またはサービス）の Indexer が作ると「管理者と SYSTEM のみ変更可・利用者は読み取り」にする。一般権限の Indexer は読み取り専用で開き、判定はできるが管理操作は「管理者として再起動」が必要
- **接続元の特定**: `NamedPipeServerStream.RunAsClient` は偽装が後続処理に残り DB に書けなくなったため、トークンを開く間だけ偽装して必ず元に戻す実装にした

## 利用者の要望による改善（2026-10-19）
- **上のバー**: エクスプローラーと同じ並びで「戻る・進む・上へ・更新」＋アドレスバー（選択中の区画のフォルダ）＋検索欄にした。検索欄には検索範囲（「PC 全体を検索」／「『フォルダ名』の中を検索」）を表示し、絞り込みの行に見出しを付けた。タブの区画が 1 つのときは区画内の戻る・アドレス欄を隠し、上のバーに一本化する（分割すると区画ごとに出る）。Ctrl+L も区画が 1 つなら上のアドレスバーを編集する
- **日付でまとめる**: ダウンロードフォルダは既定で「今日・昨日・今週・先週・今月・先月・今年・それ以前」の見出しを付ける（週の始まりは地域の設定）。ほかのフォルダも一覧右上のボタンで切り替えられ、場所ごとに覚える。受け取りボックスも届いた日でまとめる。判定は `FileBox.Core/Files/DateGroup.cs`
- **ZIP**: 圧縮ファイル（zip/7z/rar など）だけを選んでいるときは「ZIP に圧縮」を出さない
- **サイドバー**: 各見出しの右の矢印で折りたためる（アニメーション付き、状態は `sidebar.collapsed` に保存）。クイックアクセスとお気に入りの間に「最近使ったフォルダ」（5 件、クイックアクセスの場所は除く）。容量・管理・設定を下部に同じ形のアイコン付きボタンで並べ、クォータの一覧は上限があるときだけ出す
- **ごみ箱・ネットワーク**: エクスプローラーを開かず FileBox の区画で表示する。ごみ箱は各ドライブの `$Recycle.Bin\（SID）` の `$I`/`$R` を直接読み、元に戻す・完全に削除（権限確認と監査ログあり）・空にする（Windows の確認画面）に対応。ネットワークはネットワーク探索で見えるコンピューターと割り当て済みドライブを出し、コンピューター → 共有フォルダ → 通常のフォルダ表示と辿れる。`\\サーバー\共有` の直接入力も可。`shell:RecycleBinFolder` などの引数も FileBox の区画で開く
- **アイコンの色**: ファイルは種類ごとに色を付けた（PDF 赤、Word 青、Excel 緑、PowerPoint 橙、画像、動画、音楽、圧縮、コードなど）。フォルダは右クリック「フォルダの色」で 10 色から選べる（Teams のチャネル色のように）。色は FileBox の中だけの表示で `view.folderColors` に保存し、Windows 側（desktop.ini など）は変えない。サイドバーの各項目にも色を付けた
- **大きさ**: クリックするボタン・アイコンを全体に大きくした（主なボタン 40px 角、アイコン 16〜20px）。分割ボタンは向きが分かりにくいフォントのグリフをやめ、枠と仕切り線を描いたアイコンにした（左右分割＝縦線、上下分割＝横線）
- **詳細**: プレビュー区画の下に、エクスプローラーの詳細ウィンドウ相当（種類・場所・サイズ・作成／更新／アクセス日時・属性、画像の大きさ・撮影日時、動画や音楽の長さ・アーティスト、文書の作成者など）を出す。右クリックの「プレビュー・詳細」はフォルダにも出す
- **保存先の提案**: トークナイザがカタカナをひらがなに変えてから文字種を判定していたため、「エクスプローラーの」「わりとなるあぷり」のように助詞まで 1 語になっていた。カタカナとひらがなを区別して分け、送り仮名は 2 文字まで、ひらがなだけの短い語・助詞のつながり（「となる」など）は語にしない。括弧（「」『』【】など）で囲んだ語は題名・案件名として扱い、その名前のフォルダを優先する。さらに、今の場所に同じ語を含むファイルが他にもあれば、それらをまとめるフォルダ（例: `ドキュメント\ファイルボックス`）の作成を提案する
- **アイコン**: FileBox のアイコン（青い角丸に白い箱型フォルダ）を `scripts/Make-Icon.ps1` で作り、本体・ウィンドウ・ダウンローダー・インストーラーに使う
- **ショートカット**: インストーラーはデスクトップのショートカットを既定で作る。ダウンローダー（`FileBox-Setup.exe`）も展開後にデスクトップとスタートメニューへショートカットを作る（再実行すると最新の展開先に向け直す）

- **設定**: 「FileBox をエクスプローラーの代わりに使う」の 1 つのスイッチで、フォルダ・ドライブを開く操作と Win + E をまとめてオン／オフ。状態（使っている・一部だけ・ほかのアプリが上書きした）と登録した実行ファイルの場所を表示し、「個別に選ぶ」で片方だけも選べる
- **アンインストール**: インストーラーがファイルを消す前に `FileBox.exe --unregister-shell` を実行し、フォルダの動詞・Win + E・変換メニューの登録を変更前に戻す（画面は作らずに終わる）。FileBox が応答しないときの代替も、`ShellExecute` ではなく `explorer.exe` に直接渡す（置き換えた動詞で FileBox に戻ってこないように）
- **検索欄の文字の位置**: 外側の `AutoSuggestBox` だけ高さ 40 にしていたため、中の入力欄が上に寄って文字が上にずれていた。入力欄の方を高さ 40・縦中央にした（縦の位置は本体の `VerticalContentAlignment` が入力欄へ渡る）
- **見た目**: 区画が 1 つのときは区画の見出し（タブ・アドレスバーと同じ名前）を出さず、「分割」をタブの右端へ移した。フォルダの「未集計」はエクスプローラーと同じく空欄にした（理由はツールチップ）。PC ではドライブの空きだけを列に出し（合計と使用率はツールチップ）、使えない操作（新規フォルダ・切り取り・削除など）のボタンを並べない。サイドバー下のボタンの読み上げ名を見えている文字（「設定」など）と同じにした。設定のスイッチは読み上げが「オン」「オフ」だけになっていたので、見出しを名前・説明を補足として付けた

**設計から変えた点**: Win + E は 02 §7.1 の低レベルキーボードフックではなく、シェルの動詞の置き換えにした（FileBox が起動していなくても効き、タスクバーのボタンも同じ動詞を使うため）。

**検証**: `dotnet test FileBox.sln` は 256 件成功。x64 のアプリのビルドは警告・エラーなし。実画面・実機で確認したもの: 検索欄の文字（入力前の案内・入力後）が縦の中央に来ること、起動時にレジストリが書き換わること、Win + E と同じ動詞の呼び出し（`opennewwindow`）で起動中の FileBox に「PC」のタブが増えること、FileBox を終了した状態から同じ呼び出しで `--home` 付きで起動すること、設定の新しい欄の表示、`--unregister-shell` でフォルダ・ドライブ・Win + E の登録が消え画面を出さずに終わること、そのあと設定のスイッチ 1 つで両方がオンに戻り変更前の値も記録されること、PC と一覧の見た目、区画の見出しを隠したときの表示。

**未確認**: 実際の Win + E キーとタスクバーのボタン（確認時に利用者が別のアプリを操作中で、キー入力を送らなかった）、右クリックメニューの実画面での表示。
